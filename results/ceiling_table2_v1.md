# Ceilings of the training-sample comparison (Table 2; validation)

Generated by `python -m hnl.eval.ceiling_table2 summarize`. Every run of results/training_sample_val_mwslmerge.csv on its own scored val graphs (the graphs its classifier scored). Perfect classifier: score 1 for the graph edges joining consecutive hits of one particle (chain truth, docs/definitions.md section 2), 0 for every other edge. Efficiency: Table 2's (learned merging, LM, at the run's val working point). Graph ceiling (CC): connected components of the true edges in the graph (docs/definitions.md section 6). Perfect + LM: the same builder as Table 2 (first pass: same-layer Mutex Watershed at s0 0.2; then the run's own merge model at its working-point tau) on the perfect scores; merging can join fragments across a missing true edge, so it can exceed the CC ceiling. Same-particle CC: connected components of every graph edge joining two hits of one particle. Room: ceiling minus efficiency, paired over events and seeds. Uncertainties: val event bootstrap (B 1000, seed 20261005) with the seed spread / n for three-seed models; one-seed models add the seed sd of Canto-L (ttbar) for the same quantity, as Table 2.
